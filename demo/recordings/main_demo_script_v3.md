### T1 · 反问机制 + 追问闭环（0:45 → 1:25）—— 40 秒

**T1.1** 复制粘贴发送：`NL MasterCard 拒付，没收到错误码`

**T1.2** 等待 3 秒（闭嘴）

**T1.3** 你看到的回复（**软反问：明确说出缺什么**）：

```

error_code（具体错误码？如 13.1/4837）

💡 没拿到也没关系，回复「继续」我就基于现有信息先给您一份初步分析。
```

**T1.4 口播**（10 秒）：
> 「**软反问 —— bot **明确说出缺什么字段**，不是机械列 4 项（国家/渠道/错误码/订单号）。query 里 `NL` 已经抽到国家，`MasterCard` 已经抽到渠道，所以**只剩 error_code 缺失**。」
>
> 「**反问 ≠ AI 答不了**。反问是 bot **追问**信息 —— 商户补全后再诊断。这跟'AI 答不了自动派单'是两回事。**这个差异是产品上反复迭代过的**：反问不该派单，缺信息就该追问，机器人在自助阶段不打扰人工。」

**闭嘴 3 秒**

**T1.5** 复制粘贴发送（商户补全 error_code + 订单号 + 自报处置进度）：

```

```

**T1.6** 等待 3 秒（闭嘴）

**T1.7** 你看到的回复（**bot 评估「信息够了」→ 给完整 5 段诊断**）：

```

- 实物商品：物流单号 + 签收记录
- 数字商品：下载记录 + 登录日志 + 激活时间
- 都要附上和买家的沟通截图

- 以后这类拒付会自动拦截，不用每次申诉

**第三步：降低以后的拒付**
- 发货后主动给买家发物流信息
- 减少『以为没发货』的误会

需要我帮你创建工单让财务团队跟进，或开通 Collaboration 自动拦截吗？
```

**T1.8 口播**（15 秒）：
> 「**追问闭环完成 —— 完整链路**：
> 1. **bot 说缺什么**：`error_code（具体错误码？如 13.1/4837）`

>
> 「**追问功能 ≠ 反问骚扰**。只用了 **1 轮追问、商户 1 句话补全**，3 秒后 bot 给完整自助方案。这就是机器人 + 商户的协作闭环。」
